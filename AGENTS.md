# Convenciones del proyecto

## Formato de HTML

- Al crear o modificar código HTML en este proyecto, prioriza que el marcado sea fácil de leer.
- Indenta de forma consistente los elementos anidados, en especial los `div`, las filas y celdas de tablas, y los elementos de listas.
- Mantén cada nivel de anidamiento claramente alineado para que la estructura y el cierre de los elementos se distingan con facilidad.
